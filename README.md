# Student Course & Performance Management System

A Python console-based application for managing student information, courses, marks, skills, and performance.

## Features

- Add Student
- View All Students
- Search Student
- Check Pass/Fail Status
- Find Top Performers
- Display Unique Skills
- Subject-wise Performance Analysis
- Delete Student
- Menu-driven interface

## Concepts Used

This project is built using core Python concepts:

- Functions
- Lists
- Dictionaries
- Sets
- Loops
- Conditional Statements
- List Comprehension
- `zip()`
- `items()`
- `append()`
- `remove()`

## How to Run

Make sure Python is installed on your system.

Run the following command:

```bash
python main.py
```

Then select an option from the menu.
